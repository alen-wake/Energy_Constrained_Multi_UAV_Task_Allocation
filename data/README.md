# Dataset location

The source CSV is not included in this repository.

Download the **HOTOSM Turkey Destroyed Buildings (OpenStreetMap Export)** CSV
from the Humanitarian Data Exchange:

https://data.humdata.org/dataset/41765491-7345-421f-91d8-a023412e46b5

Save the file in this directory with the following name:

```text
hotosm_tur_destroyed_buildings_polygons_csv.csv
```

The experiment software reads the dataset without modifying it.
